## Domain and package

`fictional.kiln-studio` version `1.0.0` is a synthetic ceramic studio owner using Desk SDK `^1.2.0`. It records firing plans; it does not operate kiln hardware. Its runtime has no filesystem, process, network, credential, or third-party imports. Its mutable owner state is isolated by connection inside each adapter instance.

Two kiln destinations are available: Amber electric kiln and Cobalt test kiln. Four firing records are seeded: porcelain breakfast bowls, celadon tea cups, terracotta planters, and glaze test tiles. A firing contains `batchName`, `programme`, `loadNotes`, and a complete `kiln` reference. The `/kiln` relationship and drafting destination resolver are declared explicitly.

Implemented declarations and bindings:

| Capability | Behavior |
| --- | --- |
| `kiln-studio.kiln.list` | Lists annotated kiln destinations using the request connection. |
| `kiln-studio.firing.list` | Filters by full admitted destination references, returns at most two objects per page, and retains immutable snapshot rows behind opaque cursors. Four initial records span two pages when both kilns are admitted. |
| `kiln-studio.firing.watch` | Supports poll observations, scoped to source destinations, with present-object evidence and at most the requested limit or 20 objects. |
| `kiln-studio.firing.create` | Supplies conversation drafting metadata, validates that the input kiln is an authorized snapshot destination, creates only during dispatch, and returns correlated success evidence. |
| Canonical readback | The create connector declares `kiln-studio.firing.list` as its readback query capability and separately returns the current firing value or an unknown result. |

The connector advertises no deduplication, operation lookup, conditional update, or cancellation guarantee. Local setup requires no settings or credentials.

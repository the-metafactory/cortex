# PROTOTYPE: My Day one-click authority

Throwaway. Do not merge or reuse this code. It holds synthetic data in memory, calls no owner and proves no authority behaviour.

The question it settles: where does Desk ask for the standing grant behind one-click My Day changes, and how do a full Catch-up and Undo feel?

Run it from the repository root:

```bash
bun docs/prototypes/desk-my-day/index.html
```

Switch variants with the bar at the bottom. Reset restarts the scenario.

- **A:** the question appears next to the button you pressed.
- **B:** the question appears in a host card over the page.
- **C:** the question is a checkbox on Start the day. Later clicks with the grant off ask next to the button.

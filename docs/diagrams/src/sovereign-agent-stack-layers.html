Phases

1 Off the Mac→2 Agent containers + workspaces+2b Audit (in parallel)→3 Broker + passkeys→4 Agents
Phase 1 stands up a new stack with fresh identity. The Mac stack keeps running, so rollback is free.

Decisions

DD‑1 container/VM is the boundary · DD‑2 agents propose, broker executes · DD‑3 approval bound to the exact action · DD‑4 passkey for money · DD‑5 review, then approve · DD‑6 audit off-host · DD‑7 all layers in git · DD‑8 hub off the Mac · DD‑9 cloud sessions for low risk only · DD‑10 sandbox re-scoped · DD‑11 workspace = repo (Artifacts EU default)

Rules

No business credentials before Phases 2 and 2b.
Agents never hold write credentials to systems or canonical repos.
The host only pulls from git; any change made on it is drift and gets audited.
